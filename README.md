# Git&GitHub团队协作实战项目
## 项目简介
本人自主完成GitHub官方协作教程，熟练掌握代码分支管理、拉取请求创建、代码审查与版本合并整套企业开发协作流程。

## 技术栈
Git、GitHub、Pull Request、Code Review

## 实操内容
1.  分支管理：独立创建功能分支，分离开发分支与稳定主分支
2.  代码提交：完成代码修改、提交与推送操作
3.  PR流程：发起拉取请求，设置任务负责人
4.  代码评审：在线评论代码、提交修改建议、审核批准代码
5.  版本合并：合规完成分支合并，同步更新项目代码

## 学习收获
掌握互联网团队多人协同开发规范，理解代码审核的质量把控作用，具备基础团队代码协作能力，适配开发、大数据类实习岗位工作要求。
